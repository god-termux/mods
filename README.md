# god-termux/mods

Каталог модов для god-termux. Приложение (Моды → «Каталог») скачивает отсюда список `index.json` и ставит моды в `~/.termux/mods`.

- Каталог: https://god-termux.github.io/mods/index.json
- Мод = каталог `mods/<имя>/` с `mod.json`, исходниками `java/` (собираются в `classes.dex` в Actions) и, при необходимости, `lib/`.
- Версия (`"version"` в `mod.json`, целое число) повышается при каждом изменении: приложение предлагает обновление, когда версия в каталоге больше установленной.
- Мод выполняется с правами приложения. Ставьте только то, чему доверяете; в приложении есть подтверждение, а контрольная сумма проверяется по `index.json`.

Локальная сборка: `ANDROID_HOME=… bash scripts/build.sh` (результат в `site/`).
